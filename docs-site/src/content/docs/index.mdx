<Band id="start" eyebrow="Start here" title="From install to evidence in four steps" lead="The shortest route through the docs. Each step links to the page that covers it.">
<Steps>

1. **Install the gateway.** You need Python 3.10 or newer, `git` and a Nebius Token Factory key. The [Quickstart](/guides/quickstart/#the-one-minute-path) has the commands for macOS, Linux and Windows.

2. **Send your first request.** The gateway speaks the OpenAI chat-completions format, so any OpenAI SDK works. Copy an example from the next section, or see the [API guide](/reference/api/#examples).

3. **Read the `ratchet` block.** Every answer is a standard `chat.completion` plus a `ratchet` block that says who answered (`served_by`), how confident the student was and what the request cost. [The fields](/guides/quickstart/#send-your-own-request) are listed in the Quickstart.

4. **Check the evidence.** The [Results](/guides/results/) page shows the exam scores on databases the adapter never trained on, and [Evidence you can check](/guides/evidence/) shows how to verify each claim yourself.

</Steps>
</Band>

<Band id="first-request" tint eyebrow="Your first request" title="Send a request to the local gateway" lead="These are the Quickstart's tested examples. The gateway runs on port 8000; replace the key with the one you chose.">
<Tabs syncKey="first-request">
<TabItem label="curl">

```bash
curl -s http://localhost:8000/v1/chat/completions \
  -H 'content-type: application/json' \
  -H 'authorization: Bearer your-local-api-key-here' \
  -H 'X-Ratchet-Task: ticket-triage' \
  -d '{"model":"ratchet","messages":[
        {"role":"user","content":"I was charged twice for my Pro plan this month. Order #48213."}]}'
```

</TabItem>
<TabItem label="Python">

```python
from openai import OpenAI

client = OpenAI(base_url="http://localhost:8000/v1", api_key="your-local-api-key-here")
resp = client.chat.completions.create(
    model="ratchet",
    messages=[{"role": "user", "content": "I was charged twice this month."}],
    extra_headers={"X-Ratchet-Task": "ticket-triage"},
)
print(resp.choices[0].message.content)
print(resp.model_extra["ratchet"]["served_by"])  # teacher, until a trained student is serving
```

</TabItem>
<TabItem label="Node">

```js
import OpenAI from "openai";
const client = new OpenAI({ baseURL: "http://localhost:8000/v1", apiKey: "your-local-api-key-here" });
const r = await client.chat.completions.create(
  { model: "ratchet", messages: [{ role: "user", content: "Where is my order #48213?" }] },
  { headers: { "X-Ratchet-Task": "ticket-triage" } },
);
```

</TabItem>
</Tabs>

<Aside type="note" title="Real model calls">
Every call here is a real model call and costs cents, and the gateway needs your Token Factory key. Prefer not to install anything? Use the live gateway at [live.ratchet.dualmindlab.tech](https://live.ratchet.dualmindlab.tech). The [Quickstart](/guides/quickstart/) has the full setup.
