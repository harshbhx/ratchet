## The one-minute path

You need Python 3.10 or newer, `git` and a Nebius <Term t="token-factory">Token Factory</Term> key.

```bash
git clone https://github.com/harshbhx/ratchet.git && cd ratchet
pip install -e ".[dev]"
export NEBIUS_API_KEY=...        # your Token Factory key
export RATCHET_API_KEYS=me:your-local-api-key-here   # live mode needs a key for /v1/*; pick your own
mkdir -p data
RATCHET_MODE=live RATCHET_DB=./data/ratchet.db uvicorn ratchet.gateway:app --port 8000
```

The gateway serves on `http://localhost:8000`. With no <Term t="student">student</Term> endpoint, the teacher (Nemotron 3 Ultra on Token Factory) answers every request. In a second terminal, send it a request with the OpenAI SDK:

```python
from openai import OpenAI

client = OpenAI(base_url="http://localhost:8000/v1", api_key="your-local-api-key-here")
resp = client.chat.completions.create(
    model="ratchet",
    messages=[{"role": "user", "content": "I was charged twice this month."}],
    extra_headers={"X-Ratchet-Task": "ticket-triage"},
)
print(resp.choices[0].message.content)
print(resp.model_extra["ratchet"]["served_by"])  # teacher, until a trained student is serving
```

Then open `http://localhost:8000/` (the story), `/scout` (the research agents, which also need `TAVILY_API_KEY`) and `/dashboard` (releases, versions, costs).

## Install

<Tabs>
<TabItem label="macOS and Linux">

```bash
git clone https://github.com/harshbhx/ratchet.git && cd ratchet
python -m venv .venv && source .venv/bin/activate
make install
```

</TabItem>
<TabItem label="Windows (PowerShell)">

```powershell
git clone https://github.com/harshbhx/ratchet.git; cd ratchet
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -e ".[dev]" ruff
```

Windows has no `make`, so run the command `make install` stands for (the last line). In PowerShell, set variables with `$env:NEBIUS_API_KEY="..."; $env:RATCHET_API_KEYS="me:your-local-api-key-here"; $env:RATCHET_MODE="live"; $env:RATCHET_DB="./data/ratchet.db"` (after `mkdir data`) before `uvicorn`.

</TabItem>
</Tabs>

`make install` runs `pip install -e ".[dev]" ruff`. The `dev` extra brings pytest, the OpenAI Python SDK (used by the example above), `cryptography` for signed <Term t="bom">BOMs</Term>, PyYAML and Jinja2. The gateway itself needs only FastAPI, uvicorn, httpx, pydantic and anyio.

## Send your own request

The gateway speaks the OpenAI chat-completions format, so any OpenAI SDK works. Name the task with the `X-Ratchet-Task` header (or `metadata.ratchet_task`); without one, the request belongs to the task `default`. These are the examples from the [API reference](/reference/api/#examples).

<Tabs>
<TabItem label="curl">

```bash
curl -s http://localhost:8000/v1/chat/completions \
  -H 'content-type: application/json' \
  -H 'authorization: Bearer your-local-api-key-here' \
  -H 'X-Ratchet-Task: ticket-triage' \
  -d '{"model":"ratchet","messages":[
        {"role":"system","content":"You triage customer support tickets. Reply with JSON only ..."},
        {"role":"user","content":"I was charged twice for my Pro plan this month. Order #48213."}]}'
```

</TabItem>
<TabItem label="Node">

```js
import OpenAI from "openai";
const client = new OpenAI({ baseURL: "http://localhost:8000/v1", apiKey: "your-local-api-key-here" });
const r = await client.chat.completions.create(
  { model: "ratchet", messages: [{ role: "user", content: "Where is my order #48213?" }] },
  { headers: { "X-Ratchet-Task": "ticket-triage" } },
);
```

Install the SDK first with `npm install openai`.

</TabItem>
</Tabs>

Every answer is a standard `chat.completion` plus a `ratchet` block. The fields you will read most:

| Field | Meaning |
|---|---|
| `served_by` | `student` or `teacher` |
| `student_version` | The version that answered, or `null` when the teacher did |
| `confidence` | The student's confidence, if it was tried |
| `escalated` | `true` when the student was tried and was below its threshold |
| `cost_usd`, `all_teacher_cost_usd` | What this request cost, and what the teacher alone would have cost |
| `stored` | Whether a teacher answer of this request became, or matched, a training example |
| `request_id`, `row_id` | The request's id and its ledger row |

## Try Scout from the command line

```bash
export TAVILY_API_KEY=...
python -m ratchet.scout "What is LoRA fine-tuning?" --base-url http://localhost:8000/v1 --api-key your-local-api-key-here
```

<Term t="scout">Scout</Term> runs as an outside client against the gateway: a planner and a writer pinned to the teacher, a searcher, and many small triage and reader calls. It also takes `--api-key` and `--max-results` (default 4). See [Scout](/guides/scout/).

## Common questions

### Do I need an API key, a GPU or Node?

A Token Factory key, yes: every answer is a real model call. No GPU: the gateway does no inference. Node is needed only to rebuild the web app (`make web`); the build is committed.

### Where is my data?

In the <Term t="sqlite">SQLite</Term> ledger at `RATCHET_DB`. Stopping the gateway keeps it.

### Port 8000 is taken. What now?

Use another port, for example `--port 8001`, in the `uvicorn` line and in the URLs and examples.

### How do I get a student?

A student appears only after Night School trains and releases one on your ledger, which needs a GPU endpoint and a training job: see [Host it on Nebius](/guides/host-on-nebius/). Those scripts are tested offline with mock models; one retraining job, one endpoint speed test and one Night School (rejected by the golden gate, never made live) have been run by hand on Nebius. The measured results are on [Results](/guides/results/) and [Evidence](/guides/evidence/).
